Internally uses a multiset of \doxylink{classEvent}{Event} objects, which are sorted by time on insertion, nearest time first. Global time set to zero.

The event system uses indices for accessing stations and trains in the state, so the order of the items in the state {\itshape must} be preserved. The number of stations and trains passed must be the number in the state or trains will be missed/out of bounds errors will occur.

The logging file for the timestamps is also created in this constructor.
